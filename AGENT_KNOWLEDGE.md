# Agent Knowledge - SignatureCelebrations

## Project Structure
- **website/frontend/**: Contains HTML templates for the website.
- **website/backend/app.py**: FastAPI backend server.
- **venv/**: Python virtual environment.

## Key Commands
- **Run App**: `bash -c 'PYTHONPATH=. ./venv/Scripts/uvicorn.exe website.backend.app:app --host 127.0.0.1 --port 8000'`
- **Install Requirements**: `./venv/Scripts/pip.exe install -r requirements.txt`
- **Gemini CLI**: `gemini`
